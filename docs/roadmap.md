# Share MUSIC 路線変更プラン（2026年11月）

## 目的（大前提）
**新しい曲と出会う。大好きな曲をおすすめして広める。共感し合う。**
「聴くこと」は Spotify や YouTube Music がすでに得意なので、Share MUSIC は **人のおすすめで曲と出会う体験** と **共感・広がりの手応え** に集中する。

- 想定する使い手：友だち・知り合い中心（少人数でも楽しい設計にする）
- 費用：無料の範囲だけ（有料 AI などは使わない）
- 既存の「聴く」機能（プレイリスト共有・リスニングパーティー・ミックステープ等）は **残すが脇役** に
- アプリを開いた最初の画面：**今日のおすすめが並ぶ**（スワイプ型ではなく一覧）

## 作るもの

### 1. 「ここを聴いて」＋サビから試聴（核になる機能）
- **おすすめするとき**：曲を選んだら、プレーヤーで「一番聴いてほしい瞬間」を選ぶ。
  - 同期歌詞があれば行の一覧から「刺さった一行」をタップ → その行の時刻が「ここを聴いて」になる
  - 歌詞がなければつまみで秒数を指定
  - 「場面」タグ（夜の帰り道・朝・雨・ドライブ・作業・失恋・元気がほしい など）と一言を添える
- **見る人**：カードをタップすると、その瞬間から約20秒、前後の歌詞と一緒に試聴。気に入ればそのまま全曲へ
- 指定がない曲（既存の投稿など）は、同期歌詞の繰り返し部分からサビを自動推定（だめなら曲の約35%地点）。「推定サビ」と表示する
- 動画の長さと歌詞の長さを比べて、MV のイントロによるずれを自動補正し、±で微調整できるようにする

### 2. ホームを「今日のおすすめ」に
- 一番上に「今週のお題」
- 新しいおすすめ順に、カード（ジャケット・**刺さった一行を大きく**・場面タグ・おすすめした人）を並べる
- カードのタップでその場で試聴（プレーヤーは1つを使い回す。最初の1曲はタップで開始＝iPhone の自動再生制限に対応）
- 既存の棚（人気のプレイリストなど）は下の方へ

### 3. ありがとう便＋リアクション整理
- おすすめ曲のリアクションを、意味の違う3つにする：**刺さった**（いいねの置き換え）／**わかる**（共感）／**ありがとう**（教えてくれて感謝）
- 「ありがとう」はおすすめした人（「私もおすすめ」の人も）に通知。プロフィールに「ありがとうをもらった数」
- 既存のいいね数は「刺さった」に引き継ぐ
- コミュニティ（つぶやき）の絵文字リアクションはそのまま

### 4. 布教の木（広がりの見える化）
- 「ありがとう」「私もおすすめ」「お題での回答」などで、**誰から誰へ曲が届いたか** を記録する
- 曲ページ：その曲がどう広がったかを木の形で表示
- プロフィール・お知らせ：「あなたのおすすめが ○段階で ○人に届いた」

### 5. 今週のお題（1人1曲）
- 毎週のお題（運営ページで設定。未設定なら用意したリストから自動）
- 1人1曲だけ、「ここを聴いて」＋一言で答える（あとから差し替え可）
- 回答はホームの一番上に並び、週の終わりに「みんなの答え」として残る
- お題が更新されたらお知らせ

## 進め方（段階）
| 段階 | 内容 |
|---|---|
| 1 | データの準備（新しい情報はひとまとめではなく1件ずつ保存）・「ここを聴いて」の投稿と試聴・サビ推定 |
| 2 | ホーム「今日のおすすめ」・リアクション3種とありがとう便 |
| 3 | 今週のお題 |
| 4 | 布教の木 |
| 5 | 全体の見直し（メニュー構成・使い方ページ・プライバシーポリシー更新） |

- 最後にまとめ役（メイン）が組み込み・テスト・公開

## 既知のリスク（オーナー判断で現状維持）
- **CD音源の自動検索**（`ytmSongs`）は YouTube Music の内部の仕組みを使っており、YouTube API の規約（スクレイピング禁止）に触れる恐れがある。問題が起きたら公式 API で公式動画を探す方式に切り替える。
- **歌詞の全文表示**は権利者（JASRAC 等）の許諾がない。指摘を受けたら前後数行の表示に切り替える。

## 規約上守ること
- YouTube の埋め込みは 1画面に1つ・200×200 以上・見える状態・前面に何も重ねない。音の出る自動再生はしない（タップで開始）
- 試聴は公式の開始秒指定（start / seekTo）で行う
